# Workflow Ontology Study Programme

This directory contains study-specific protocols and artefacts used to validate the Cognitive Workflow Ontology.

The canonical programme-level plan is:

- [`../docs/RESEARCH_VALIDATION_PLAN.md`](../docs/RESEARCH_VALIDATION_PLAN.md)

## Study sequence

```text
001 — Content validation
Establish workflow accuracy, demand coverage, cognitive-function relevance,
intervention loci, outcomes and claims safety.

002 — Behavioural validation
Test whether mapped demands and function-specific measures predict held-out
workflow performance.

003 — Intervention pilot
Test whether cognitive training, workflow redesign or their combination improves
separate cognitive and workflow outcomes.
```

## Status convention

Each study README should report one of:

```text
planned
protocol drafting
preregistered
recruiting
data collection
analysis
reported
closed / retired
```

## Required separation

Every study must distinguish:

```text
workflow evidence
cognitive-demand evidence
function-mapping evidence
protocol-fit evidence
workflow-outcome evidence
implementation evidence
```

No study result should silently promote all six evidence dimensions at once.
