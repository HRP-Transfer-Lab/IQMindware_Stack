# Study 003 — Workflow Intervention Pilot

**Status:** planned after behavioural validation  
**Study family:** intervention and implementation evaluation  
**Programme plan:** [`../../docs/RESEARCH_VALIDATION_PLAN.md`](../../docs/RESEARCH_VALIDATION_PLAN.md)

## Purpose

Test whether a configured cognitive-support route, workflow redesign, or their combination improves separate cognitive and workflow outcomes.

## Preferred comparison

| Condition | Purpose |
|---|---|
| Measurement or active control | Estimate change without the targeted route. |
| Workflow redesign only | Test task, interface or process support. |
| Cognitive training only | Test the person-level protocol route. |
| Combined route | Test training plus workflow support. |

## Outcome hierarchy

```text
app learning
→ separate cognitive measure
→ simulated functional task
→ real workflow outcome
→ delayed persistence
→ implementation outcome
```

## Main evidence dimensions

```text
P3 — separate cognitive transfer
P4 — functional workflow transfer
O1–O3 — feasibility, pilot and controlled outcome evidence
I2–I3 — acceptability, feasibility and implementation evidence
```

## Required implementation outcomes

- acceptability;
- appropriateness;
- feasibility;
- adoption;
- fidelity;
- participant burden;
- practitioner or manager burden;
- cost;
- equity and accessibility;
- privacy and trust;
- unintended effects.

A positive training-game result alone cannot satisfy this study’s success criteria.
