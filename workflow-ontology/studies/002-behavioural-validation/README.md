# Study 002 — Behavioural Validation

**Status:** planned after Study 001  
**Study family:** prospective predictive validation  
**Programme plan:** [`../../docs/RESEARCH_VALIDATION_PLAN.md`](../../docs/RESEARCH_VALIDATION_PLAN.md)

## Purpose

Test whether the ontology’s mapped workflow demands and cognitive functions predict relevant held-out workflow behaviour.

## Candidate first demonstrator

AI-output verification with controlled variation in:

- source density;
- contradictions;
- interruptions;
- time pressure;
- plausibility of unsupported claims;
- context switches;
- decision reversibility.

## Candidate outcomes

- unsupported claims detected;
- source-attribution errors;
- false alarms;
- review time;
- interruption re-entry time;
- confidence and calibration;
- premature release;
- excessive checking.

## Main evidence dimensions

```text
D3 — behaviourally supported demand mapping
F3 — prospectively predictive cognitive-function mapping
P2 — exact app implementation characterised, where applicable
```

This study does not by itself establish that cognitive training causes workflow improvement.

## Design requirements

- prespecified primary outcomes;
- held-out or prospective validation sample;
- explicit competing explanations;
- separate person and workflow predictors;
- timing and data-quality controls;
- uncertainty and abstention reporting;
- no tuning and testing on the same cases.
